# RAG Blueprint

Code behind the **RAG Blueprint** series on LinkedIn: one carousel a week, one step of a retrieval-augmented generation pipeline per episode. Every number on the slides comes from a script in this repo, run on public data.

No framework. Each episode is plain Python so every step stays visible.

These are small, single-question experiments meant to show how each step behaves. They are not benchmarks.
